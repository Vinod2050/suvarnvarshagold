Suvarnavarsha Gold - settings for GoDaddy (Node.js app -> Secrets / Environment variables)
=========================================================================================

1) SET BY GODADDY AUTOMATICALLY when the hosted MySQL database is attached.
   Do NOT add, change or override these yourself - just check they are listed in the Secrets card:

   DB_HOST
   DB_PORT
   DB_NAME
   DB_USER
   DB_PASSWORD


2) ADD (private, 8+ characters each; GoDaddy sets NODE_ENV itself - it is reserved):

   SUPERADMIN_PASSWORD = <temporary super admin password>   -> creates account "superadmin"
   ADMIN_PASSWORD      = <admin password>                   -> creates account "admin" (limited)

   Each account is created only if it does not exist yet; an existing one is never changed.
   Super admin: everything, incl. Users (add / remove / lock / unlock / reset password) and Settings.
   Admin: daily rates, ad videos, customer feedback, store products and FAQs only.
   Change the passwords after the first sign-in; the settings can then be deleted.
   Optional: SUPERADMIN_USERNAME / ADMIN_USERNAME to use other names.


3) ADD LATER, when the domain is connected (no slash at the end):

   SITE_URL = https://suvarnvarshagold.com


4) OPTIONAL - only if the troubleshooting steps in DEPLOY-GODADDY.md tell you to:

   AUTO_MIGRATE = false        (only after importing database/setup-all.sql by hand)


Not needed on GoDaddy (the app handles them itself):
   PORT, HOST, SESSION_SECRET, IP_HASH_SALT, SETUP_TOKEN, TRUST_PROXY (default 1 is right)

Do not upload a .env file: GoDaddy's Secrets card is the right place, and the ZIP does not contain one.

5) SUPER ADMIN PASSWORD NOT WORKING / FORGOTTEN (emergency reset):

   SUPERADMIN_PASSWORD        = <the new password, typed by hand - not browser autofill>
   RESET_SUPERADMIN_PASSWORD  = yes

   Save (the app restarts). The log shows: Password of super admin "superadmin" set from SUPERADMIN_PASSWORD
   (account unlocked). Sign in, then DELETE the RESET_SUPERADMIN_PASSWORD row - otherwise every restart
   sets the password again.
